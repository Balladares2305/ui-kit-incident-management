# UI Kit - Sistema de Gestión de Incidentes

## Descripción

UNIVERSIDAD TÉCNICA DE MANABÍ 
DANNY ENRRIQUE BALLADARES

Se ha creado una biblioteca de componentes visuales reutilizables (UI Kit) diseñada con CSS3 puro para el sistema de gestión de incidentes.

## Componentes incluidos
-  Botones (8 variantes, 3 tamaños)
-  Formularios (inputs, select, textarea)
-  Tarjetas (cards)
-  Alertas (6 niveles)
-  Insignias (badges)

##Tecnologías
- HTML5
- CSS3 (variables, flexbox, grid)
- Git & GitHub
